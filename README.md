# Strata

Muscle, heart and bone training in one phone web app. Successor to Lift Log.

- 4-day Upper / Legs rotation with automatic progression, plate math, swaps, injury holds and a lighter-day mode
- Jumps warm-up before leg days (bone), 4×4 interval timer and office-day steps (heart)
- Weekly Muscle / Heart / Bone rings, history, progress charts
- Imports a Lift Log export; data stays in the browser (export to back up)

Live: https://nicolasruiza.github.io/strata/
